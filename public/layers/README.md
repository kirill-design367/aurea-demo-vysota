# Фотослои параллакса — как подставить

Фон построен на 4 слоях. Каждый движется по скроллу со своей скоростью (дальние
пики почти стоят, передний склон летит), туман плывёт поверх и дрейфует сам.
Пока файла нет — виден мягкий туман/дымка/небо (аккуратный плейсхолдер). Как
только положишь PNG сюда (`public/layers/`) с точным именем — слой подхватится
сам, кроп и скорость уже настроены.

## Требования ко всем слоям

- Формат: **PNG-24 с альфа-каналом** (прозрачный фон — видно небо между слоями).
- Ориентация: горизонтальная панорама, террейн прижат к нижней кромке, сверху прозрачно.
- Ширина: **3840 px** (покрывает до 4K-десктопа, вниз масштабируется чётко).
- Вес: желательно ≤ ~500 КБ (пришлёшь как есть — оптимизирую через sharp, как фото).

## Файлы (точные имена)

| Файл | Что в кадре | Размер (px) | Пропорция | Скорость параллакса |
|------|-------------|-------------|-----------|---------------------|
| `layer-1-peaks.png`  | Дальние пики / силуэт у горизонта | 3840×2160 | 16:9 | самый медленный |
| `layer-2-ridge.png`  | Средний хребет | 3840×2160 | 16:9 | средний |
| `layer-3-forest.png` | Передний склон с лесом (крупно, вдоль низа) | 3840×2400 | 8:5 | самый быстрый |
| `layer-4-fog.png`    | Полосы/клубы тумана, мягкие полупрозрачные края | 3840×1600 | 12:5 | плывёт + дрейф |

Порядок наложения (от дальнего к ближнему): peaks → ridge → **fog** → forest.
Туман (`layer-4-fog.png`) специально между хребтом и лесом — даёт объём.

## Свет

Смена времени суток (рассвет → золотой час → закат) реализована **наложением
цветокоррекции** (blend-слои) поверх фотослоёв и меняется по скроллу — сами PNG
перекрашивать не нужно, присылай в нейтральном/дневном свете.

## Мобильная версия

Не нужна — демо смотрится только с десктопа.
