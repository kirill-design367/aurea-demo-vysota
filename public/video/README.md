# Видео для Hero (бумеранг-фон)

Сюда нужно положить **один короткий ролик** горного пейзажа — и Hero оживёт.

## Что именно

- Файл: **`hero.mp4`** (H.264/MP4). Можно добавить и `hero.webm` — но код грузит `hero.mp4`.
- Длина: **5–10 секунд**, сюжет плавный и «зацикливаемый» (техника бумеранга
  сама доигрывает вперёд-назад, так что резкий стык в конце не страшен).
- Сюжет: **туман / плывущие облака между хребтами**, медленное движение,
  холодный горный свет. Без людей, текста и логотипов.
- Ориентация: **горизонтальная**, ≥ 1920×1080. Вес желательно до ~15–20 МБ.

## Где взять бесплатно (лицензия позволяет коммерческое использование)

- **Pexels Video** — pexels.com/search/videos/mountain%20fog/
- **Coverr** — coverr.co (раздел Nature)
- **Mixkit** — mixkit.co/free-stock-video/mountain/
- **Videvo** / **Pixabay Video** — по запросам «mountain fog», «clouds ridge», «alpine mist».

Скачайте клип, при желании обрежьте до 5–10 сек и переименуйте в `hero.mp4`,
положите в эту папку, закоммитьте — превью подхватит его автоматически.

## Пока файла нет

Hero не сломан: сзади показывается холодный CSS-туман (лёгкая анимация дымки),
поэтому кадр выглядит цельно и без ролика. Как только `hero.mp4` появится —
компонент `BoomerangVideoBg` захватит его кадры и запустит бесшовный цикл.
